### 📶 Data Science Projects

### 🏛️ [Expected Credit Loss](https://github.com/Axelcodeml/Expected_Credit_Loss)

**Deployment of ML Application** to predict the Expected Credit Loss for the Portfolio loss in a Bank. The general equation to calculate is: `ECL = PD x LGD x EAD` It inputs an CSV to read all the Portfolio Loss Data and esitimates the losses by the product of three models: PD, LGD and EAD.

| Tab | Route | What is it for |
|---|---|---|
| **Tab** | `/` | Load a CSV, process the portfolio and analyze results |
| **Individual Credit** | `/credito` | Estimate PD, LGD, EAD y ECL of only one credit |
| **Model** | `/modelo` |  Consult metodologies, metrics, assumptions and limits |
| **Historic** | `/historial` | Review previous runs and download CSV | 
<br>

**_Stack_**: Python, FastAPI, NextJS, RestAPI <br>
**_AI Agents_**: Codex, OpenCode, DeepSeek

### ⚽ [World Cup 2026 Predictions](https://github.com/Axelcodeml/Mundial2026_Predictions)
**Who will win the World Cup 2026?** This project responds with data extracted by using Web Scrapping provided from different web pages of football results. It applies a pipeline to extract, cleand and train two XGBoost Models and simulates 50.000 world cups with **Monte Carlo Simulation** to estimate the performance of each football team until predict the results of the 104 matches of the tournament
<br> 
**Pipeline:** 
1. Scraping
2. Data Cleaning
3. Feature Enginnering
4. Modeling
5. Stochastic Monte Carlo simulation
6. Matches Prediction
7. Web Application for Prediction<br>

**_Stack:_** Python, BeautifulSoup, XGBoost, MonteCarlo, HTML, GitHub Actions
